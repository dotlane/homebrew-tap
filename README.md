# Dotlane Homebrew tap

```bash
brew install dotlane/tap/dotlane
dotlane install        # once: the login service, the certificate authority, the DNS route
dotlane add myapp 5173 # https://myapp.traix → localhost:5173
```

[Dotlane](https://github.com/dotlane/dotlane) gives local dev servers real, trusted HTTPS
addresses. macOS only for now (Apple Silicon and Intel).

## Upgrading and removing

- `brew upgrade dotlane`, then any `dotlane` command restarts the service on the new version.
- To remove it: `dotlane uninstall` first (add `--purge` to delete the sites and the certificate
  authority), then `brew uninstall --zap dotlane`. `brew uninstall` alone cannot undo
  `dotlane install`, which needed your password, so the service would keep running.

## How this tap is updated

`Casks/dotlane.rb` is generated by GoReleaser for each Dotlane release and pushed here when the
release is published (`scripts/tap-update.sh` and `.github/workflows/tap.yml` in
[dotlane/dotlane](https://github.com/dotlane/dotlane)), with a deploy key that can write to this
repository only. Do not edit it by hand: the next release replaces it. Pre-releases are not
published here.

Report problems at [dotlane/dotlane](https://github.com/dotlane/dotlane/issues).
